 Название бота

Краткое описание: игра-угадайка в Telegram с системой побед, таблицей лидеров и блокировкой после 3 проигранных попыток.

## Возможности

- Угадывание числа от 1 до 6
- 3 попытки на раунд, после проигрыша — перманентная блокировка
- Подсчёт побед и сохранение в SQLite
- Таблица лидеров (игроки с 20+ победами)
- Команда /start для начала игры
- Логирование в файл с ротацией
- Токен бота хранится в .env

## Технологии

- Python 3.10+
- pyTelegramBotAPI
- SQLite3
- python-dotenv
- Logging (RotatingFileHandler)
